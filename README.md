# Pink LSZ Plugin
A plugin for the Pink LSZ clan. It records your drops, kill counts, collection log, combat achievements, personal bests and deaths as you play, and sends them to the clan dashboard (https://dashboard.pinkosrs.com) for leaderboards, boss stats, member profiles and clan events.

Only current clan members are accepted. Install it, log in, and add your RuneScape name to your dashboard profile.

## What it sends
- Drops, kill counts, collection log and combat achievements
- Personal bests, with a screenshot
- Deaths at bosses and raids, with a screenshot (can be turned off)
- Screenshots of valuable drops and of items the clan is watching for during events

Everything goes to the dashboard over HTTPS and nowhere else, along with your character name and account hash. Screenshots can show public chat; private messages are hidden.
